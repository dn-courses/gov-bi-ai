Write the `name` column alone, once in each order, encoded and not compressed:

```duckdb
COPY (SELECT name FROM 'station_status.parquet' ORDER BY captured_at, station_id)
  TO 'enc_name_by_time.parquet' (FORMAT parquet, COMPRESSION uncompressed);
COPY (SELECT name FROM 'station_status.parquet' ORDER BY station_id, captured_at)
  TO 'enc_name_by_station.parquet' (FORMAT parquet, COMPRESSION uncompressed);

SELECT file_name, any_value(encodings) AS encoding,
       round(sum(total_uncompressed_size) / 1e6, 1) AS encoded_mb
FROM parquet_metadata(['enc_name_by_time.parquet', 'enc_name_by_station.parquet'])
GROUP BY ALL ORDER BY encoded_mb DESC;
```

A Parquet file records, for every column, the encoding it used and its size before and after
compression. DuckDB reads that record with `parquet_metadata`.

<Scene widget="enc-file">
<Step>

```duckdb
SELECT path_in_schema AS column_name, any_value(encodings) AS encoding,
       round(sum(total_uncompressed_size) / 1e6, 1) AS encoded_mb
FROM parquet_metadata('station_status.parquet')
GROUP BY ALL ORDER BY encoded_mb DESC;
```

`station_status.parquet` was written with the defaults: the older format version, compressed.
Write the same rows three more ways:

```duckdb id=writes
COPY (SELECT * FROM 'station_status.parquet')
  TO 'enc_uncompressed.parquet' (FORMAT parquet, COMPRESSION uncompressed);
COPY (SELECT * FROM 'station_status.parquet')
  TO 'enc_v2_uncompressed.parquet' (FORMAT parquet, PARQUET_VERSION v2, COMPRESSION uncompressed);
COPY (SELECT * FROM 'station_status.parquet')
  TO 'enc_v2.parquet' (FORMAT parquet, PARQUET_VERSION v2);

SELECT file_name, any_value(compression) AS compression,
       round(sum(total_uncompressed_size) / 1e6, 1) AS encoded_mb,
       round(sum(total_compressed_size) / 1e6, 1) AS on_disk_mb
FROM parquet_metadata(['enc_uncompressed.parquet', 'station_status.parquet',
                       'enc_v2_uncompressed.parquet', 'enc_v2.parquet'])
GROUP BY ALL ORDER BY encoded_mb DESC, on_disk_mb DESC;
```

```python needs=writes
import duckdb, time

QUERY = "SELECT count(DISTINCT captured_at), sum(docks_available) FROM '{}'"
READ = """SELECT round(sum(total_compressed_size) / 1e6, 1) FROM parquet_metadata('{}')
          WHERE path_in_schema IN ('captured_at', 'docks_available')"""
FILES = ["enc_uncompressed.parquet", "station_status.parquet",
         "enc_v2_uncompressed.parquet", "enc_v2.parquet"]

def best(con, file, runs):
    times = []
    for _ in range(runs):
        start = time.perf_counter()
        con.sql(QUERY.format(file)).fetchall()
        times.append(time.perf_counter() - start)
    return min(times) * 1000

con = duckdb.connect()
for file in FILES:
    read_mb = con.sql(READ.format(file)).fetchall()[0][0]
    print(f"{file:28} reads {read_mb:6.1f} MB   best of 5: {best(con, file, 5):5.1f} ms")
```

</Step>
