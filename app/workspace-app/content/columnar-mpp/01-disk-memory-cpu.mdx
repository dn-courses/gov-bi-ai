The table this part works on: one row per bike-share station every five minutes, 1,000 stations, 90
days. Building it takes about a minute.

```sql id=build-table
DROP TABLE IF EXISTS station_status;
CREATE UNLOGGED TABLE station_status AS
SELECT s AS station_id,
       (ARRAY['NYC','JC','BOS','CHI','DC','SF'])[1 + s % 6] AS system_id,
       t AS captured_at,
       (10 + 8*sin(s + extract(epoch from t)/14400) + (hashint4(s + extract(epoch from t)::int) % 3))::smallint AS bikes_available,
       (12 - 8*sin(s + extract(epoch from t)/14400))::smallint AS docks_available,
       (hashint4(s*31 + extract(epoch from t)::int) & 3)::smallint AS ebikes_available,
       (hashint4(s*7 + extract(epoch from t)::int) & 1)::smallint AS bikes_disabled,
       (hashint4(s*13 + extract(epoch from t)::int) & 1)::smallint AS docks_disabled,
       true AS is_renting, (s % 50 <> 0) AS is_returning, true AS is_installed,
       t - interval '20 seconds' AS last_reported,
       'Station ' || s || ' — ' || (ARRAY['Broadway & W 58 St','Grove St PATH','Harvard Square at Mass Ave','Clark St & Elm St','Columbus Circle / Union Station','Market St at 10th St'])[1 + s % 6] AS name,
       '{"vehicle_types_available":[{"vehicle_type_id":"1","count":' || (10 + (s % 7)) || '},{"vehicle_type_id":"2","count":' || (s % 4) || '}]}' AS vehicle_types,
       md5(s::text) AS legacy_id
FROM generate_series(timestamptz '2026-07-01', timestamptz '2026-09-28 23:55', interval '5 min') t,
     generate_series(1, 1000) s;
```

The same table written as a file, which later pages read. This also takes about a minute.

```duckdb id=write-parquet needs=build-table
SELECT count(*) AS rows FROM 'station_status.parquet';
```

```sql needs=build-table
SELECT current_setting('block_size')              AS page_bytes,
       pg_relation_size('station_status') / 8192  AS pages;
```

Every row has an address, `ctid`: its page, then its place on the page. The rows of page 600000:

```sql needs=build-table
SELECT ctid, station_id, system_id, captured_at, bikes_available
FROM station_status
WHERE ctid >= '(600000,0)' AND ctid < '(600001,0)';
```

How many rows the page holds, and how many bytes a row takes:

```sql needs=build-table
SELECT count(*) AS rows_on_the_page,
       avg(pg_column_size(s.*))::int AS bytes_per_row
FROM station_status s
WHERE ctid >= '(600000,0)' AND ctid < '(600001,0)';
```

</Step>

```sql

FROM pg_settings
WHERE name = 'shared_buffers';
```

An average over the table's first 10,000 pages. `Buffers` is the bytes moved, in pages; `rows` is
