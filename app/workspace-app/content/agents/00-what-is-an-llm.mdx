Gemini's tokenizer, asked directly. `compute_tokens` cuts the text and returns the pieces; no reply is written.

```python
import os

from google import genai

client = genai.Client()  # Vertex AI: project and location come from the environment
MODEL = os.environ["GEMINI_MODEL"]

for text in ["The customer who has spent the most is", "film", "film_category", "KARL SEAL", "BUCKET BROTHERHOOD"]:
    tokens = client.models.compute_tokens(model=MODEL, contents=text).tokens_info[0].tokens
    print(f"{len(tokens)} tokens  {[t.decode() for t in tokens]}")
```

<Step>

This model does not report its probabilities, so measure them: send the same text 30 times and count how each reply starts.

```python
import asyncio
from collections import Counter

from google.genai import types

PROMPT = "The customer who has spent the most is"
CONTINUE = types.GenerateContentConfig(system_instruction="Continue the user's text. Output only the continuation.")

draws = await asyncio.gather(*[client.aio.models.generate_content(model=MODEL, contents=PROMPT, config=CONTINUE) for _ in range(30)])
for word, n in Counter(d.text.split()[0] for d in draws).most_common():
    print(f"{n:>3} of 30  {word}")
```

The schema as text, counted by the same model's tokenizer:

```python
import psycopg

with psycopg.connect(os.environ["DATABASE_URL"]) as conn:
    tables = conn.execute("""
        SELECT c.table_name, string_agg(c.column_name || ' ' || c.data_type, ', ' ORDER BY c.ordinal_position)
        FROM information_schema.columns c
        JOIN information_schema.tables t USING (table_schema, table_name)
        WHERE c.table_schema = 'public' AND t.table_type = 'BASE TABLE' AND c.table_name NOT LIKE 'payment_p%'
        GROUP BY c.table_name ORDER BY c.table_name""").fetchall()

schema = "\n".join(f"{name}({columns})" for name, columns in tables)
print(schema[:190], "…")
print(len(tables), "tables,", client.models.count_tokens(model=MODEL, contents=schema).total_tokens, "tokens")
```
