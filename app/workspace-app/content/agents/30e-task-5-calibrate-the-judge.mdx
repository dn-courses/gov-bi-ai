good. The judge is one more component, so it is measured before its scores are believed.

<Step>

The judge: one model call. The rubric is its instruction, the case is the message, and structured
output makes it return a verdict and a reason, the reason first.

```python id=judge
import asyncio, os
from typing import Literal

from google import genai
from google.genai import types
from pydantic import BaseModel

client = genai.Client(http_options={"timeout": 30_000, "retry_options": {"attempts": 2}})  # a call that hangs fails after 30 s, retried once
MODEL = os.environ["GEMINI_MODEL"]


class Verdict(BaseModel):
    reason: str
    verdict: Literal["good", "bad"]


def shown(case):
    """What the judge reads: the question, what the agent did, and its answer."""
    did = case["did"].strip() or "(no tool was called)"
    return f"QUESTION\n{case['question']}\n\nWHAT THE AGENT DID\n{did}\n\nTHE AGENT'S ANSWER\n{case['answer'].strip()}"


async def judge(case, rubric):
    """One model call: the rubric as the instruction, the case as the message, a Verdict back."""
    reply = await client.aio.models.generate_content(model=MODEL, contents=shown(case), config=types.GenerateContentConfig(
        system_instruction=rubric, response_mime_type="application/json", response_schema=Verdict))
    return reply.parsed


print(shown(CASES[1]))
```

"Too lenient" means the judge passed an answer the person failed; "too strict", the other way.

```python id=score
RUNS = 3


async def score(rubric):
    runs = [await asyncio.gather(*(judge(case, rubric) for case in CASES)) for _ in range(RUNS)]
    print(f"{'case':15} {'human':6} judge, {RUNS} runs")
    for i, case in enumerate(CASES):
        labels = [run[i].verdict for run in runs]
        note = "" if set(labels) == {case["human"]} else "<- flips" if len(set(labels)) > 1 else "<- disagrees"
        print(f"{case['id']:15} {case['human']:6} {' '.join(f'{v:5}' for v in labels)} {note}")
    agreement = [sum(run[i].verdict == case["human"] for i, case in enumerate(CASES)) for run in runs]
    print(f"\nagreement: {', '.join(map(str, agreement))} of {len(CASES)}\n")
    for i, case in enumerate(CASES):
        wrong = next((run[i] for run in runs if run[i].verdict != case["human"]), None)
        if wrong:
            side = "too lenient" if wrong.verdict == "good" else "too strict"
            print(f"{case['id']} ({side})\n  judge: {wrong.reason}\n  human: {case['why']}\n")
```

<Step>

The judge and the cases are fixed; only the rubric moves. Read each disagreement as the question
"what did the person check that the rubric never asked?", and write the answer down as a rule. For
`boston_hour`, too lenient: the person checked whether anything in the answer is claimed without a
result behind it. The judge sees what the agent saw: every call, and each result with at most six
of its rows, which the layer sorts by the metric, largest first. The judge knows only what the
rubric tells it, so a fact the person relied on (that order, say) belongs in the rubric too.

A rule can overshoot: a rubric that fails every long answer is too strict on one of the good ones.
A case that flips between runs is one the rubric leaves to chance.

A judge costs a model call per answer, and its verdict on the same answer can change between runs.
It reads what the agent read, so where the data itself is wrong it has nothing to disagree with:
that is the value check's job, written by a person from the table.

```python id=fresh needs=30-evals-and-observability#reference
from google.adk.agents.run_config import RunConfig
from google.adk.runners import InMemoryRunner


def call_text(name, args):
    return f"{name}(" + ", ".join(f"{key}={value!r}" for key, value in args.items()) + ")"


def result_text(r):
    """A tool result as the cases show it: without the SQL, and at most six rows."""
    r = {key: value for key, value in r.items() if key != "sql"}
    if len(r.get("rows", [])) > 6:
        r["rows"] = r["rows"][:6] + [f"... {len(r['rows']) - 6} more rows"]
    return f"  -> {r}"


async def answer_case(question):
    """Ask the warehouse agent; return what the judge reads: the question, the calls and results, the answer."""
    runner = InMemoryRunner(agent=agent.root_agent, app_name="warehouse_agent")
    session = await runner.session_service.create_session(app_name="warehouse_agent", user_id="me")
    did, answer = [], ""
    async for event in runner.run_async(user_id="me", session_id=session.id, run_config=RunConfig(max_llm_calls=8),
                                        new_message=types.Content(role="user", parts=[types.Part(text=question)])):
        did += [call_text(call.name, dict(call.args)) for call in event.get_function_calls()]
        did += [result_text(dict(response.response)) for response in event.get_function_responses()]
        if event.is_final_response() and event.content and event.content.parts:
            answer = (event.content.parts[0].text or "").strip()
    return {"question": question, "did": "\n".join(did), "answer": answer}
```
